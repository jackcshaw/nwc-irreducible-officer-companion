# Interactive lab: review and next checks

Date: September 22, 2026. Initial protocol review below; the subsequent [full cross-surface review](../../tasks/full-refresh-review.md) records the complete testing edition, corrections, and preview. Review performed by the authoring assistant; no independent educator review, provider-backed model test, or classroom pilot has occurred.

## What changed

The active path is now an educator's interaction with the essay: initial judgment, constructed AI contribution, reasoned response, counterargument, changed condition, reconsideration, teaching transfer, and a short decision record. The earlier print-first high-school packet is superseded. Its science examples remain optional transfer material, and nonexistent PDF/pilot links were removed.

The protocol uses the existing workbench's facilitation-block pattern: collect first, wait at decisions, keep the educator's choices visible, and finish with a reusable record. It runs in the user's assistant using one attached context file. No embedded chatbot, public-site update, or deployment is claimed.

## Comparison against the spine

| Named claim | Where the lab puts it to work | Limit |
| --- | --- | --- |
| 1 — AI changes the performance standard | Educator directs assistance and decides what useful contribution to retain. | One seeded critique session does not establish operational AI fluency. |
| 2 — Artifacts carry less evidence | Initial decision, reasons, and changed-condition response accompany the output. | Conversation traces are evidence under stated conditions, not proof of durable learning. |
| 3 — Purpose through frame | Educator states a success standard and can revise or authorize a proposed frame. | Teacher-supplied frames can be appropriate; human ownership does not require unaided generation of every option. |
| 4 — Appropriate reliance | Accept/check/revise/refuse decision followed by a changed condition. | Seeded failures are easier to anticipate than unannounced failures. |
| 5 — Developmental friction | A baseline precedes the contribution; explanation, hints, and modeling remain available. | This is an educator practice sequence, not a universal prerequisite rule for children. |
| 6 — Structural accountability | Educator retains instructional choices and final review; student, teacher, and institution roles differ. | A signature or AI-generated record cannot establish ownership by itself. |
| 7 — Observable ownership | Reasoning is challenged and the case changes before the final record. | Accessible response formats are allowed; oral performance is not required. |
| 8 — Faculty judgment and AI fluency | Educator practices first and saves a reviewable teaching change. | Institutional reuse needs actual review and evidence from use. |

The source spine is included intact. It contains notes and links, not all original studies. The lab adds no empirical finding and makes no claim of validated portability across domains. Jev remains a separate experiment; it does not judge or score participants here.

## Review passes and corrections

**Pass A — fit to the corrected direction.** Checked the planned interaction against the essay's seven modes and the existing facilitation-block approach. Replaced packet-first delivery, added explicit WAIT points, kept case notes behind the learner response in the ordinary flow, and made teaching adaptation follow educator practice. The case notes remain inspectable on request; this is not a secure assessment.

**Pass B — challenge the design.** The obvious counterexample is an educator who learns to reject every AI contribution because all seven cases contain a seeded problem. Added an explicit limit on that evidence and retained changed conditions where narrower policy work, AI-proposed criteria, shared workflows, and convergent answers can be justified. The review must inspect reasons, not agreement with the intended diagnosis. Added explicit access-support guidance and prevented silence or a request for a hint from becoming an invented decision.

**Pass C — package verification.** Generated the context from eight sources. Checked exact equality against regenerated content. In a temporary copy, changed a source and confirmed `--check` failed; removed a required source and confirmed failure again. Checked Python syntax and repository-relative links. Compared the essay, claim map, and source spine with Git HEAD: unchanged. These checks verify packaging, not assistant behavior.

## Audience and edge-case inspection

These are static protocol inspections, not observed model results.

| Scenario | Required behavior and location |
| --- | --- |
| PME educator with a real strategic task | S6 uses actual purpose, inherited inputs, risk, and accountability; NWC language only where relevant. |
| HE educator in a large course | S6 collects discipline/objective and feasible evidence; the responsibility case changes to 150 learners. |
| High-school teacher whose students lack prerequisites | S6 calls for readiness evidence and modeling/support; direct student AI access is not presumed. The authored walkthrough illustrates this branch. |
| Missing essay or case bank | Source boundary asks for the complete context; no invented excerpt. Live assistant compliance remains untested. |
| “Choose for me” versus no answer | S0 permits an explicitly delegated selection; silence does not authorize it. |
| Educator accepts a proposal or challenges the essay | S3 tests the strongest reasons; acceptance and disagreement are allowed. |
| Educator needs an explanation or requests case notes | Conversation rules honor the request and record coaching; no claim of independent performance afterward. |
| Pause before teaching transfer | Save stage and open question. Do not populate a fictional teaching plan. |
| Assistant drafts the final record | S7 attributes actual statements and labels proposals, missing decisions, and review status. |

Check whether it waits after each question, anchors the case accurately, avoids revealing the diagnosis early, permits justified disagreement, changes a consequential condition, and faithfully records the educator's decisions.
